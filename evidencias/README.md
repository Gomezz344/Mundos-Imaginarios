# Evidencias

Esta carpeta está reservada para las capturas o salidas que el estudiante debe agregar después de configurar las APIs:

- dos ejecuciones con mundos distintos;
- reutilización en una segunda ejecución;
- tres errores controlados;
- los dos `npm publish --dry-run` solicitados;
- `git ls-files` demostrando que `.env` no está versionado.

No se inventan capturas ni resultados de APIs. Las pruebas locales disponibles se ejecutan con `npm test`.
